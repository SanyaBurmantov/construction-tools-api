# Разборы аварий (postmortems)

После каждой аварии, которую заметили покупатели или которая могла потерять
данные, пишется короткий разбор: что случилось, почему, что изменили, чтобы
не повторилось. **Без поиска виноватых** — разбор ищет причину в системе
(не было алерта, не было лимита, шаг требовал человека), а не в человеке.

Зачем: следующая похожая авария узнаётся за минуту, а не за час; решения
«почему здесь лимит / почему так странно» перестают быть загадкой; видно,
какие классы проблем повторяются.

## Как писать

1. Скопировать [`TEMPLATE.md`](TEMPLATE.md) в `ГГГГ-ММ-ДД-коротко.md`.
2. Заполнить в течение пары дней, пока помнятся детали. Время — по Минску.
3. Каждое «что изменили» — ссылкой на коммит или задачу. Если ничего не
   изменили — так и написать и объяснить почему.
4. Самое важное правило — в CLAUDE.md, чтобы его не «упростили» обратно.
