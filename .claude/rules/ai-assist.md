# ИИ-помощник

Восемь фоновых работ DeepSeek, правило границы, предложения и «Отклонённое».

- **ИИ-помощник** (`ai/assist/`, `/admin/ai?tab=assist` «Помощник»).
  DeepSeek как работник внутри магазина: восемь работ, у каждой выключатель
  и дневной лимит (`SiteSetting ai.assist.<job>`, учёт дня по Минску —
  `ai.assist.usage.<job>`). **Все выключены по умолчанию** — платный ключ не
  начинает тратить при выкатке. `AiAssistCron` в воркере (каждую минуту в
  :30, не в :00 раннера задач) делает **один шаг одной** включённой работы —
  не больше одного запроса к модели — по кругу; работа без дела отдыхает
  `idleMinutes`, ошибка — 15 мин, 429 ставит на паузу весь ключ,
  порог баланса (`/admin/ai`, затем `AI_MIN_BALANCE`) останавливает как и задачи, `AI_ASSIST_ENABLED=false` —
  всё сразу. «Шаг сейчас» в админке выполняет шаг в API. **Правило границы**:
  модель выбирает только среди того, что ей дали (`assist/assist-prompts.ts`,
  чистые парсеры с тестами), и сама меняет лишь то, что дёшево исправить и
  откатывается; остальное — `AiSuggestion` (kind+key уникальны, отклонённое
  не предлагается снова) с «Принять / Отклонить / Откатить».
  1. **autopilot** — раз в час, пока прошлая его задача не закончилась,
     ставит обычную `AiTask` (`createdBy` = «ИИ-помощник», шаблон и поля из
     настроек) на опубликованные товары без ИИ-текстов (`aiLockedFields`
     без текстовых полей; лучшие карточки и новые первыми).
  2. **categorize** — товары резервной «Неразобранные товары поставщиков»:
     кандидаты = категории товаров, которые FTS находит по виду товара, +
     похожие по имени (`similarity`), только видимые; `high` применяется сразу
     и закрепляет `categoryId` в `aiLockedFields` (перепарсинг не вернёт),
     `low` ждёт админа (он может выбрать другого кандидата).
  3. **synonyms** — запросы «ничего не найдено» (≥2 раза за 30 дней) →
     группа основ; хранится, только если с ней поиск находит товары, а без
     — нет. Принятые — `SiteSetting search.synonyms`, `buildFtsQuery(term,
     extra)`; `ProductService` перечитывает их раз в минуту.
  4. **leads** — новая заявка QUESTION → `Lead.aiDraft` (текст + товары из
     соседей по категории и FTS по словам сообщения); цены и наличие модель
     не пишет, менеджер копирует черновик со ссылками в «Заявках».
  5. **specs** — по корневым разделам по кругу: одинаковые характеристики под
     разными `canonicalKey` (одна единица, не идентичность). Принятое —
     `SiteSetting spec.aliases` (`catalog-normalizer/spec-aliases.ts`),
     нормализатор применяет его после `canonicalSpec()` каждую ночь, а
     `Specification` переписывается сразу. **Не откатывается** (ночное
     слияние строк необратимо).
  6. **duplicates** — мнение same/different/unsure по группам
     `/admin/duplicates` (ключ `signal:key`, пересчёт при смене состава),
     только совет — значок на странице.
  7. **landings** — `BrandCategoryLanding` для (бренд, категория) с ≥6
     товарами: h1, текст, SEO, проверки `validateAnswer`; прошедшие
     публикуются сами. Адрес — **`/catalog/<категория>/<бренд-slug>`**
     (`pages/catalog/[category]/[brand].vue` → `CatalogView` с `landing`:
     бренд из пути всегда выбран, в query не пишется, снять его = уйти в
     категорию; свой h1/title/description/текст, хлебная крошка бренда и
     **canonical на себя**). Страница бренда ссылается туда, когда посадочная
     опубликована (`BrandCategory.landing`), старый `?brands=<id>` с
     посадочной — 301 на красивый адрес; скрытая посадочная — 302 обратно в
     фильтр. Sitemap категорий добавляет опубликованные
     (`GET /storefront/landings`, их сбой не роняет sitemap).
  8. **variants** — товары бренда+категории, которых правила не связали
     (`ProductFamily` нет или одиночка) → «Линейка» + подписи; подпись — только
     числа из имени товара. Принятое пишет `variantLine/variantLabel` и
     `contentUpdatedAt` (воркер связей пересобирает семью за тик).
  **«Отклонённое»** (`/admin/ai?tab=rejected`): что ИИ предложил, а сайт
  не взял, — слева «сейчас на сайте», справа предложение с причиной и
  редактор. Тексты: поля задач, отклонённые проверками (`AiTaskItem.rejected`
  + сырой `response`), «Записать на сайт» пишет как ИИ-правку
  (`applyRejected`: `aiLockedFields`, `changes` пункта — откат задачи её
  тоже вернёт), «Оставить как есть» — `AiTaskItem.resolved`. Категории:
  товары резервной категории, которых помощник не разместил или не был
  уверен (пока товар там) — выбор из кандидатов ИИ или всего дерева,
  «Спросить ИИ ещё раз» удаляет предложение. Редактор товара открывается
  ссылкой `/admin/products?edit=<id>`.
